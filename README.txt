感谢seymourimadeit制作的guardvillagers模组。

本模组只有一个物品——警卫号角，玩家可以通过获得“村庄英雄”效果后由农民，武器匠和盔甲匠这三个职业的村民赠予获得，或者可以通过8个绿宝石和一个山羊角合成获得。

本模组在玩家成功一次抵御袭击后即可使用（即获得“村庄英雄”成就），每三分钟即可召唤3个跟随你的警卫并获得无限时间的一级“村庄英雄”。

本模组有一些额外可配置的功能：
1.僵尸和灾厄村民（包括掠夺兽和女巫）互相仇视
2.警卫近战是否能后撤 
3.灾厄村民（含劫掠兽、女巫）额外敌对的生物

本模组中警卫号角的冷却时间，召唤警卫的数量，以及额外功能的开关均可以在配置文件修过。
